## 🚀 Projects

### 1. Number Guessing Game

**Folder:** `Num_game`

A number guessing game where users try to guess a randomly generated number.

**Features:**
- Number guessing functionality
- Interactive user interface
- Game result feedback

**Technologies:** Java, HTML, CSS, JavaScript

### 2. Student Grade Calculator

**Folder:** `Student_grade_cal`

A student grade calculator that calculates results based on entered marks.

**Features:**
- Enter student marks
- Calculate grades
- Display results

**Technologies:** Java, HTML, CSS, JavaScript

### 3. Student Course Registration System

**Folder:** `Student course_regd`

A course registration application for managing student and course information.

**Features:**
- Student information management
- Course registration
- Registration interface

**Technologies:** Java, HTML, CSS, JavaScript

### 4. ATM Interface

**Folder:** `ATM_interface`

An ATM simulation application for performing basic banking operations.

**Features:**
- Balance inquiry
- Deposit functionality
- Withdrawal functionality

**Technologies:** Java, HTML, CSS, JavaScript

### 5. Quiz Application with Timer

**Folder:** `Quiz app_timer`

An interactive quiz application that includes a timer for answering questions.

**Features:**
- Display quiz questions
- Timer functionality
- Calculate quiz results

**Technologies:** Java, HTML, CSS, JavaScript
